# Echo Loop 使用指南（批量 + 语言切换）

把素材丢一个文件夹，跑一条命令 → 输出 `_echo.m4a` + `_echo.lrc`，目标语 ↔ 中文 循环跟读。

## 1. 一键切换语言

`--lang ja` = 日 → 中；`--lang en` = 英 → 中。一个 flag 同时切换 Google 和 edge-tts 的目标语音色。

```bash
# 批量日 → 中
python main.py --scan ./lessons --lang ja

# 批量英 → 中
python main.py --scan ./lessons --lang en
```

不带 `--lang` 时用 [config.yaml](../config.yaml) 里的默认（当前是日 → 中）。

| `--lang` | Google target voice | edge target voice |
|---|---|---|
| `ja` | `ja-JP-Chirp3-HD-Charon` | `ja-JP-NanamiNeural` |
| `en` | `en-US-Chirp3-HD-Charon` | `en-US-JennyNeural` |

中文（native）始终是 `cmn-CN-Chirp3-HD-Kore`。

模拟面试模式也支持同一个语言开关：

```bash
# 英语面试 → 中文
python main.py --interview interview.txt --lang en

# 日语面试 → 中文
python main.py --interview interview.txt --lang ja

# 只切换面试角色声音，不影响普通 target voice
python main.py --interview interview.txt --interview-lang ja
```

面试模式下，`Q:` / `Interviewer:` 使用 interviewer voice，`A:` / `Candidate:` 使用 interviewee voice；具体预设在 [config.yaml](../config.yaml) 的 `interview.presets` 里。

## 1.5 交互式菜单

不想每次拼命令时，直接运行：

```bash
python main.py -i
```

菜单会依次让你选择：

- 批量文件夹 / 单个文本 / 单个音频+LRC
- 目标语言预设（日语或英语）
- TTS 引擎（Google / edge-tts / OpenAI）
- Loop 模式（full / progressive / shadow / 自定义重复次数）
- 是否拆分输出 `_tnt` 和 `_tst`

如果 `config.yaml` 里没有配置输入路径，直接运行 `python main.py` 时也会自动进入同一个菜单。

## 1.6 模拟面试模式

模拟面试文本用角色前缀区分提问者和回答者，但每一行仍然保留普通文本模式的 `英文|||中文` 格式：

```text
Q:Tell me about yourself.|||请介绍一下你自己。
A:Sure. I’m a backend engineer with five years of experience.|||当然。我是一名有五年经验的后端工程师。

Interviewer:Why do you want this role?|||你为什么想要这个岗位？
Candidate:I’m interested because the role combines product thinking with infrastructure work.|||我感兴趣是因为这个岗位结合了产品思维和基础设施工作。
```

支持的提问者前缀：`Q:`、`Question:`、`Interviewer:`。
支持的回答者前缀：`A:`、`Answer:`、`Candidate:`、`Interviewee:`。

运行：

```bash
python main.py --interview interview.txt
```

这个模式复用文本模式的节奏、Loop、拆分输出、音量和导出设置。目标语部分会按 `Q` / `A` 使用两套不同声音，中文翻译仍然使用普通 native TTS 声音。日语面试可以用 `--lang ja` 或 `--interview-lang ja`。

## 2. 输入文件格式

每行 `<目标语句>|||<中文翻译>`。`#` 开头注释，空行忽略。

**纯文本 `.txt`：**
```
今日はいい天気ですね|||今天天气真好啊
The vaccine requires only one dose|||该疫苗只需接种一次
```

**音频 + LRC（同名 `xxx.mp3` + `xxx.lrc`）：**
```
[00:00.39]The vaccine requires only one dose|||该疫苗只需接种一次
```

## 3. 批量

把文件丢进一个文件夹，扫描器自动配对 `mp3 + lrc`，独立处理 `.txt`：

```bash
# 全部（音频对 + 纯文本都处理）
python main.py --scan ./lessons --lang en

# 只处理音频+LRC
python main.py --scan ./lessons --lang en --mode audio

# 只处理纯文本
python main.py --scan ./lessons --lang en --mode text
```

已存在 `_echo.m4a` 和 `_echo.lrc` 的项会自动跳过，可断点续跑。

## 4. 常用调整

```bash
# 临时换声线（覆盖 --lang）
python main.py --scan ./lessons --lang ja \
    --google-target-voice ja-JP-Chirp3-HD-Kore       # 日语女声

# 含数学/技术符号 → 切 OpenAI
python main.py --scan ./lessons --lang en --engine openai

# TTS 降 6dB
python main.py --scan ./lessons --lang en --gain -6
```

## 5. 节奏（[config.yaml](../config.yaml)）

```yaml
timing:
  after_first_target: 0.8     # 第一遍目标语后停顿
  after_native: 0.5           # 中文后停顿
  after_second_target: 1.2    # 第二遍目标语后停顿

loop:
  variant: "progressive"      # full / progressive / shadow
  tnt_repeats: 1              # 1 遍 T-N-T
  tst_repeats: 1              # 1 遍 T-S-T 影子跟读
  split_outputs: true         # 分别输出 _tnt 和 _tst；可在 UI/CLI 覆盖
```
