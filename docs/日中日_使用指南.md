# 日 - 中 - 日 Echo Loop 生成指南

通过字幕（LRC）或纯文本生成 **日语 → 中文 → 日语** 的循环跟读音频。

底层是 [main.py](../main.py) 的 Echo Loop 模式，每段音频按 `T-S-N-S-T-S` 结构拼接：

```
[日语原音] → [静音0.8s] → [中文TTS] → [静音0.5s] → [日语原音] → [静音1.2s]
```

T = Target = 日语，N = Native = 中文。重复一次日语就形成"日-中-日"。

---

## 1. 准备：选择输入形式

有两种典型场景，按你手头有什么资料选：

### 场景 A：有日语原音 + 日语 LRC 字幕（推荐）

第二个"日"是真人发音，听感最自然。需要：

- `lesson.mp3`（NHK 新闻、日剧片段、播客等）
- `lesson.lrc` —— 每行格式：`[mm:ss.xx]<日文><分隔符><中文>`

LRC 示例（分隔符默认 `|||`）：

```
[00:00.39]一度の接種でハシカのMMRワクチンについて|||关于一次接种即可预防麻疹的MMR疫苗
[00:06.74]厚生労働省の専門家部会は了承しました|||厚生劳动省的专家委员会已批准
[00:13.20]ワクチンは1回の接種で十分です|||该疫苗只需接种一次即可
```

> 没有中文翻译？先用 ChatGPT/DeepL 把每行翻好，再用 `|||` 拼起来。

### 场景 B：只有日语文本（无原音）

两段语言都用 TTS 合成。准备一个 `phrases.txt`：

```
# 日 → 中
今日はいい天気ですね|||今天天气真好啊
電車に乗り遅れました|||我没赶上电车
このラーメンは美味しいです|||这碗拉面很好吃
```

格式：`<日文><分隔符><中文>`。空行和 `#` 开头的注释会被跳过。

## 2. 配置：调到日 - 中 - 日

打开 [config.yaml](../config.yaml)，确认 `tts.google` 段（Google Cloud TTS 是默认引擎，最稳）：

```yaml
tts:
  engine: "google"

  google:
    target_voice: "ja-JP-Neural2-B"           # 日语男声 Neural2
    native_voice: "cmn-CN-Chirp3-HD-Kore"     # 中文女声 Chirp3-HD
    speaking_rate: 1.0
    pitch: 0.0

  gain: -6           # TTS 音量比原音稍低 6dB，听感更舒服
```

> 仓库当前默认就是这个组合，可以直接跑。

### 想要不同声线

| 需求 | `target_voice` 推荐 | `native_voice` 推荐 |
|---|---|---|
| 日语女声 + 中文男声 | `ja-JP-Neural2-C` | `cmn-CN-Wavenet-B` |
| 日语男声 + 中文女声（默认） | `ja-JP-Neural2-B` | `cmn-CN-Chirp3-HD-Kore` |
| 全免费（用 edge-tts） | 见下方"免费方案" |  |

完整 Google 日语/中文音色列表：<https://cloud.google.com/text-to-speech/docs/voices>

### 免费方案（edge-tts，无需 API Key）

```yaml
tts:
  engine: "edge"
  target_voice: "ja-JP-NanamiNeural"      # 日语女声
  native_voice: "zh-CN-XiaoxiaoNeural"    # 中文女声
  rate: "+0%"
```

### 节奏调整

```yaml
timing:
  after_first_target: 0.8    # 第一遍日语后停顿（给大脑反应时间）
  after_native: 0.5          # 中文翻译后停顿
  after_second_target: 1.2   # 第二遍日语后停顿（段落间隔）

loop:
  variant: "progressive"      # full / progressive / shadow
  tnt_repeats: 2              # 每段重复 2 次"日-中-日"
  tst_repeats: 1              # 再加 1 次"日-静音-日"做影子跟读
```

`progressive` + `tnt_repeats: 2, tst_repeats: 1` 是适合通勤记忆的强度，可按自己听感调。

## 3. 运行

### 场景 A：音频 + LRC

```bash
# 位置参数即可
python main.py lesson.mp3 lesson.lrc

# 输出：lesson_echo.m4a + lesson_echo.lrc（默认写在源文件旁）
```

指定输出路径：

```bash
python main.py lesson.mp3 lesson.lrc \
    -o out/lesson_jpcn.m4a \
    --output-lrc out/lesson_jpcn.lrc
```

### 场景 B：纯文本

```bash
python main.py --text phrases.txt
# → phrases_echo.m4a + phrases_echo.lrc
```

### 批量：一整个文件夹

把素材丢进 `lessons/`，然后：

```bash
python main.py --scan ./lessons
```

扫描器会自动配对 `xxx.mp3 + xxx.lrc`，独立处理 `*.txt`，每个文件输出 `xxx_echo.m4a` + `xxx_echo.lrc`。

### 临时换声音不改 config

```bash
# 改成日语女声 + 中文男声跑一次
python main.py --text phrases.txt \
    --google-target-voice ja-JP-Neural2-C \
    --google-voice cmn-CN-Wavenet-B
```

## 4. 前置依赖

只需做一次：

```bash
# Python 包
pip install -r requirements.txt

# ffmpeg（m4a 导出必需）
brew install ffmpeg
```

Google TTS 凭据：

1. Google Cloud Console → IAM → 服务账号 → 创建 JSON key（角色：Cloud Text-to-Speech User）
2. 保存为项目根的 `google-credentials.json`
3. `.env` 写入：

   ```
   GOOGLE_APPLICATION_CREDENTIALS=./google-credentials.json
   ```

如果改用 `edge` 引擎，跳过以上步骤，零配置。

## 5. 实战推荐流程

1. 找一段 1–3 分钟的 NHK Easy News 或日剧短片段，存为 `news01.mp3`
2. 用 [transcription_server.py](../transcription_server.py) 自动生成日语 LRC（详见 [README.md](../README.md#optional-transcription-api)），或自己听写
3. 把每行后面拼上 `|||中文翻译`，存为 `news01.lrc`
4. 跑 `python main.py news01.mp3 news01.lrc`
5. 把 `news01_echo.m4a` 放进手机，配合 `news01_echo.lrc` 跟读

输出长度约为原音的 4–6 倍（取决于 `tnt_repeats` / `tst_repeats`），适合通勤循环。

## 6. 用 pipeline 脚本（推荐日常用法）

`~/bin/` 下有几个封装好的脚本，把 `subtitle-automation`（生成字幕）和 `echoEnglish --scan`（生成 echo loop）串成一条流水线。引擎已统一为 **Google Cloud TTS**，日中日开箱即用。

| 脚本 | 用途 |
|---|---|
| `echo_pipeline` | 主力。`npm run dev` 生成字幕 → 自动检测新文件夹 → google TTS 生成 echo loop |
| `echo_pipeline_translate` | 同上，但跑 `npm run dev:translate`（翻译流程不同时用） |
| `echo_pipeline_openai` | 同 `echo_pipeline`，加 `--openai` 切换到 OpenAI 引擎处理数学/技术内容 |

### 自动选语音（看文件夹名）

| 文件夹名包含 | target voice (Google) | native voice |
|---|---|---|
| `Japanese`（不分大小写） | `ja-JP-Neural2-B` 日语男声 | `cmn-CN-Chirp3-HD-Kore` 中文女声 |
| `English` | `en-US-Neural2-F` 英语女声 | `cmn-CN-Chirp3-HD-Kore` |
| 其他 | `en-US-Neural2-F`（默认） | `cmn-CN-Chirp3-HD-Kore` |

**所以"日中日"的关键就是：** SYNC_DIR 下的文件夹名里带上 `Japanese` 这个词，例如 `2025-05-09_Japanese_News`、`Japanese_Anime_EP01`、`nhk_Japanese_easy`。

### 常用调用

```bash
# 完整流水线：subtitle-automation 跑出新文件夹，自动 echo loop
echo_pipeline

# 已有 audio+LRC 文件夹，直接生成 echo loop
echo_pipeline --echo /path/to/2025-05-09_Japanese_News

# 含数学/技术符号的内容，用 OpenAI 读
echo_pipeline_openai --echo /path/to/folder --openai
```

脚本固定走 `--mode audio`，只处理 `audio + LRC` 配对，纯文本 `.txt` 不会被扫到。要批量处理纯文本，用 `python main.py --text` 或自己改脚本。

### 想换声音

脚本里硬编码了 voice，要改的话编辑 `~/bin/echo_pipeline` 中的：

```bash
get_target_voice() { ... }      # 改 target（日/英）
NATIVE_VOICE="cmn-CN-Chirp3-HD-Kore"   # 改 native（中文）
```

例如想要日语女声，把 Japanese 分支改成 `ja-JP-Neural2-C`。

### 前置条件

```bash
# Google 凭据（已经配过的话跳过）
echo 'GOOGLE_APPLICATION_CREDENTIALS=./google-credentials.json' >> /Volumes/SP/code/python/echoEnglish/.env

# subtitle-automation 的 SYNC_DIR
cat /Volumes/SP/code/subtitle-automation/.env | grep SYNC_DIR

# 用 OpenAI 分支时还需要
echo 'OPENAI_API_KEY=sk-...' >> /Volumes/SP/code/python/echoEnglish/.env
```

## 7. 速查

| 想做的事 | 改哪里 |
|---|---|
| 换日语/中文声音 | [config.yaml](../config.yaml) `tts.google.target_voice` / `native_voice` |
